#  RescuePets - Trạm Cứu Hộ & Bảo Trợ Động Vật

![ASP.NET Core](https://img.shields.io/badge/ASP.NET%20Core-8.0-blueviolet)
![Bootstrap](https://img.shields.io/badge/Bootstrap-5.3-purple)
![License](https://img.shields.io/badge/License-MIT-green)

**RescuePets** là một hệ thống website hiện đại được thiết kế nhằm hỗ trợ các trạm cứu hộ động vật. Dự án không chỉ là nơi đăng tải thông tin các bé thú cưng đang chờ nhận nuôi, mà còn tích hợp các tính năng quan trọng như báo cáo cứu hộ khẩn cấp, quyên góp tài chính tự động qua VietQR, và cập nhật tin tức, tạp chí chuyên ngành.

##  Tính Năng Nổi Bật

*   **Giao diện hiện đại & Thân thiện:** Sử dụng Bootstrap 5.3 kết hợp phông chữ Times New Roman truyền thống và các hiệu ứng chuyển động mượt mà.
*   **Video Background Ấn Tượng:** Tích hợp YouTube Iframe làm nền cho Hero Section, tự động phát, lặp lại và có lớp phủ tối giúp tăng độ tương phản cho văn bản.
*   **Danh sách Thú Cưng (Pets):** Hiển thị danh sách các bé thú cưng (Teddy, Bella, Prince...) kèm theo thông tin chi tiết và nút "Nhận Nuôi".
*   **Hệ Thống Đơn Nhận Nuôi (AJAX):** Form đăng ký nhận nuôi được xử lý bất đồng bộ, gửi dữ liệu về Server mà không cần tải lại trang.
*   **Quyên Góp Tự Động (VietQR):** Tích hợp sinh mã QR Code ngân hàng (MBBank) tự động dựa trên số tiền và tên người ủng hộ.
*   **Bản Đồ Tương Tác (Leaflet):** Hiển thị vị trí trạm cứu hộ trực quan trên bản đồ số.
*   **Đọc Báo & Tạp Chí (Modals):** Trải nghiệm đọc bài viết, phóng sự ngay trên trang chủ với tính năng tăng/giảm cỡ chữ và in ấn.
*   **Responsive 100%:** Tương thích hoàn toàn trên các thiết bị di động, máy tính bảng và máy tính để bàn.

##  Công Nghệ Sử Dụng

*   **Backend:** C# / ASP.NET Core MVC (Razor Views)
*   **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
*   **Thư viện UI:** Bootstrap 5.3, FontAwesome 6, Google Fonts (Dancing Script, Times New Roman)
*   **Bản đồ:** Leaflet.js & OpenStreetMap
*   **Thanh toán:** VietQR API
*   **Cơ sở dữ liệu:** SQL Server (Entity Framework Core)
